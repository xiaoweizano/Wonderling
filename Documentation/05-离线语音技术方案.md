# 05 离线语音技术方案

## 1. 目标
在 Android 设备本地完成录音、语音活动检测（VAD）和英语单词识别（ASR），并将结果交给 Unity。第一阶段不承诺专业级儿童发音评分。

## 2. 能力定义
- 录音：采集麦克风 PCM/编码音频。
- VAD：判断音频中是否存在语音。
- ASR：识别语音内容。
- 发音评估：评估发音与目标音素/参考发音的接近程度。

ASR 识别正确不等于发音准确；ASR confidence 不能直接当发音分数。

## 3. 技术路线
优先做 sherpa-onnx Android Spike：
1. 确认 Android ABI、最低系统版本和依赖。
2. 选择适合离线英语词汇识别的模型。
3. 测量模型文件大小、初始化耗时、常驻内存和推理延迟。
4. 在 4GB 与主流设备测试。
5. 验证飞行模式完整运行。
6. 再决定是否集成到正式 Kotlin 插件。

如需自定义发音评估，再独立评估 ONNX Runtime 或专用模型，不将其与 ASR 混为一谈。

## 4. 推荐调用流程
```text
Unity 请求录音
  -> Kotlin 检查权限
  -> Android AudioRecord 采集
  -> VAD 判断语音段
  -> sherpa-onnx 离线识别
  -> Kotlin 返回结构化结果
  -> Unity 主线程接收
  -> 教学规则决定反馈
```

## 5. C# 接口草案
```csharp
public sealed class SpeechResult
{
    public bool Success { get; init; }
    public string RecognizedText { get; init; }
    public float? Confidence { get; init; }
    public int DurationMs { get; init; }
    public string ErrorCode { get; init; }
    public string ErrorMessage { get; init; }
}
```
生产实现应考虑 Unity 当前 C# 语言版本兼容性；如不支持 `init`，使用普通属性。

## 6. 错误处理
- 权限拒绝：说明用途，允许继续课程或跳过跟读。
- 无语音：提示再试一次或播放示范。
- 识别失败：不判定为错误发音。
- 模型加载失败：禁用跟读识别，课程其余部分可用。
- 录音被系统中断：停止并清理，提供重试。
- 进入后台：停止录音并释放音频资源。

## 7. 儿童隐私
- 默认完全本地处理。
- 不上传录音或识别音频。
- 原始录音放临时目录，处理完成及时删除。
- 不记录不必要的原始语音。
- 若保存学习统计，仅保留完成情况等最少数据。
- 麦克风权限说明应清晰、适龄。

## 8. Spike 验收
必须交付：
- 设备型号、Android 版本、RAM。
- ABI 和模型名称/版本。
- 模型体积。
- 初始化耗时。
- 识别延迟。
- 内存峰值。
- 识别样例与失败样例。
- 飞行模式测试结果。
- 权限拒绝和应用后台测试结果。

没有真实设备结果，不得标记离线语音已验证。
