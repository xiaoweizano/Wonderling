# 03 课程引擎设计

## 1. 设计目标
课程内容由 JSON 描述，Unity C# 引擎负责解释和执行。新增课程优先通过配置与资源完成，不为每节课复制业务代码。

## 2. 数据结构
顶层字段：
- `schemaVersion`
- `courseId`
- `title`
- `worldId`
- `ageRange`
- `durationMinutes`
- `objectives`
- `assets`
- `steps`

Step 公共字段：
- `stepId`
- `type`
- `next`
- `onCorrect`
- `onIncorrect`
- `retryPolicy`
- `teacherAction`
- `timeoutPolicy`

任务专属字段由对应 Step DTO 定义。反序列化后必须进行语义校验，不能只检查 JSON 语法。

## 3. 示例课程
```json
{
  "schemaVersion": 1,
  "courseId": "animal_001",
  "title": "Meet the Animals",
  "worldId": "animal_forest",
  "ageRange": "3-6",
  "durationMinutes": 6,
  "objectives": ["recognize_cat", "recognize_dog", "recognize_duck"],
  "steps": [
    {"stepId":"welcome","type":"teacher_intro","teacherAction":"Greeting","audioId":"fox_welcome","next":"teach_cat"},
    {"stepId":"teach_cat","type":"word_learning","word":"cat","imageId":"animal_cat","audioId":"word_cat","next":"listen_cat"},
    {"stepId":"listen_cat","type":"listening_choice","audioId":"word_cat","options":["animal_cat","animal_dog","animal_duck"],"correctAnswer":"animal_cat","next":"repeat_cat"},
    {"stepId":"repeat_cat","type":"repeat_speech","word":"cat","audioId":"word_cat","next":"teach_dog"},
    {"stepId":"teach_dog","type":"word_learning","word":"dog","imageId":"animal_dog","audioId":"word_dog","next":"teach_duck"},
    {"stepId":"teach_duck","type":"word_learning","word":"duck","imageId":"animal_duck","audioId":"word_duck","next":"match_animals"},
    {"stepId":"match_animals","type":"drag_match","next":"memory_game"},
    {"stepId":"memory_game","type":"memory_cards","next":"challenge"},
    {"stepId":"challenge","type":"challenge","next":"complete"},
    {"stepId":"complete","type":"level_complete","reward":{"stars":3}}
  ]
}
```
这是结构样例；正式课程必须补齐任务参数、提示、资源 ID、分支和 Schema 校验。

## 4. Step 执行机制
- `StepDefinition`：不可变配置对象。
- `StepExecutor`：运行时步骤执行器接口。
- `StepExecutorRegistry`：按 type 注册执行器。
- `LessonRunner`：按步骤 ID 驱动流程。
- `TaskContext`：向任务传递课程 ID、步骤配置、服务接口和取消令牌。
- `TaskResult`：返回完成状态、正确性、尝试次数、耗时和反馈类型。

禁止把所有步骤塞进一个超长 switch。可使用注册表和明确的执行器类。

## 5. 跳转与校验
- `next` 必须引用存在的 stepId，或明确标记课程结束。
- 分支不能形成未声明的无限循环。
- 每个 stepId 唯一。
- 资源 ID 必须存在于本地资源清单。
- 必填参数按任务类型校验。
- 未知 `schemaVersion` 应拒绝加载并给出明确错误。
- 对循环复习等合法循环必须设置次数/退出条件。

## 6. 任务结果与反馈
任务只报告事实结果。反馈策略由 `AdaptiveLearningController` 统一决策。
建议结果字段：
`status`、`isCorrect`、`attempts`、`elapsedMs`、`answerId`、`feedbackTags`、`speechResult`。

## 7. 暂停与恢复
- 应用进入后台时暂停教学音频和任务计时。
- 录音进行中进入后台应安全停止并清理。
- 进度保存当前 courseId、stepId、必要任务状态和更新时间。
- 恢复时先验证课程版本与资源，再恢复到安全边界。
- 不要求恢复到录音中途的音频帧位置。

## 8. 课程配置编辑原则
第一阶段可手工维护 JSON，但必须提供校验工具或启动时校验报告。未来可制作课程编辑工具，不在当前 Demo 范围内。
