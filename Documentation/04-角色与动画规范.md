# 04 角色与动画规范

## 1. 角色定位
第一阶段主老师为 Fox（狐狸老师）。角色形象应亲切、稳定、易辨识，适合 3–6 岁儿童。不要使用过度写实、惊吓或复杂细节。

## 2. Blender 交付内容
- 原始 `.blend` 文件。
- 导出 FBX。
- 贴图与材质源文件。
- 骨骼结构说明。
- 动画清单。
- Unity 导入预制体。
- 资源授权/来源记录。

## 3. 命名约定
角色：`CHR_Fox`
骨架：`RIG_Fox`
动画：
- `Fox_Idle`
- `Fox_Greeting`
- `Fox_Speaking`
- `Fox_Listening`
- `Fox_Thinking`
- `Fox_Encourage`
- `Fox_Celebrate`
- `Fox_Guide`

动物：
- `ANM_Cat`
- `ANM_Dog`
- `ANM_Duck`

文件名使用英文、数字和下划线，避免空格和特殊字符。

## 4. 动画状态
| 状态 | 表现 |
|---|---|
| Idle | 自然呼吸、眨眼、轻微重心变化 |
| Greeting | 面向孩子挥手、微笑 |
| Speaking | 轻微头部/手势变化，配合口型 |
| Listening | 身体略前倾、专注表情 |
| Thinking | 短暂思考动作，不表现焦虑 |
| Encourage | 点头、竖拇指或温和鼓励 |
| Celebrate | 开心庆祝，动作幅度适中 |
| Guide | 指向目标或引导视线 |

## 5. 制作规范
- 先确定统一角色比例、朝向、单位和骨架规范，再制作多个角色。
- 应用一致的骨骼命名和必要的 Avatar 兼容规范。
- 动画循环首尾平滑。
- 避免过多骨骼、面部 BlendShape 和材质槽。
- 模型面数、贴图分辨率和骨骼数量以目标设备测试为准。
- 优先制作可复用动作，不为每个单词单独制作复杂动作。

## 6. 口型与语音同步
第一版采用基础口型：闭口、开口、宽口/圆口等简化形态。通过音频事件或时间标记驱动；不要求实时音素级唇形同步。无口型资源时必须有自然的 Speaking 动作替代。

## 7. Unity 导入验收
- 比例、朝向、材质正确。
- 骨骼绑定无明显错位。
- 动画无穿模和明显抖动。
- Animator 状态切换可控。
- 移动端性能符合目标。
- 资源可在目标 Android 设备实际运行。
