# 09 测试与验收标准

## 1. 验收原则
“代码存在”不等于“功能完成”。每项能力分别记录实现、自动化测试、Android 构建和真实设备验证状态。

## 2. 功能验收
### 启动
- APK 可安装、启动、退出和再次启动。
- 无网络时可进入课程。
- 无强制登录、在线授权或远程资源请求。

### 老师与场景
- Fox 正确显示。
- 语义动作可触发且状态可恢复。
- 音频播放稳定。
- 动画切换无明显卡顿或冲突。

### 课程引擎
- 有效 JSON 可加载。
- 无效 JSON 能报告具体错误。
- 步骤按配置执行。
- 分支和资源 ID 校验有效。
- 暂停、恢复、退出行为正确。
- 课程进度可以恢复。

### 互动任务
- 点击选择可正确判断。
- 听力任务播放正确音频。
- 拖动配对可完成、可取消。
- 记忆翻牌规则正确。
- 综合挑战可完成。
- 连续点击不产生重复提交。
- 任务退出后事件和资源得到清理。

### 语音
- 权限请求合理。
- 可录音、停止和清理。
- 飞行模式下可识别（若该能力通过 Spike）。
- 识别失败不阻断课程。
- 不把 ASR confidence 当作发音分数。
- 原始录音不会上传，临时文件及时删除。

### 数据
- 课程进度持久化。
- 任务记录可查询。
- 数据库升级成功。
- 异常退出后数据一致。
- 删除本地档案时关联数据按策略删除。

## 3. 离线验收流程
1. 从设备卸载旧版本。
2. 开启飞行模式并确认 Wi-Fi/移动网络关闭。
3. 安装本次交付 APK。
4. 首次启动。
5. 进入动物森林课程。
6. 完成所有教学和互动环节。
7. 执行跟读任务或验证明确的降级路径。
8. 完成课程并查看奖励。
9. 关闭应用并重新启动。
10. 检查进度和数据。
11. 检查日志，确认没有必需网络请求。

若任何关键资源需要联网获取，离线验收失败。

## 4. 性能测试
目标设备档位：
- 4GB RAM Android 设备。
- 6GB 或以上主流 Android 设备。
- Android 平板。

记录：
- 设备型号、系统版本、RAM、SoC、GPU。
- 冷启动耗时。
- 场景加载耗时。
- 稳态帧率和明显卡顿。
- CPU/GPU 使用情况。
- 内存常驻与峰值。
- 语音模型初始化耗时、内存和推理延迟。
- 连续运行时发热和内存增长。
- APK/AAB 体积。

性能门槛应在选定设备后通过基线测试确定，不在无数据情况下虚构固定指标。

## 5. 稳定性与异常测试
- 麦克风权限拒绝。
- 音频设备不可用。
- 模型文件缺失或损坏。
- 课程 JSON 缺字段。
- 音频/图片资源缺失。
- 快速重复点击。
- 应用切后台再返回。
- 系统中断录音。
- 课程中途强制关闭。
- 内存压力和场景重复加载。

## 6. 发布阻断条件
以下任一情况存在，不得宣称 Demo 验收完成：
- 飞行模式无法完成核心课程。
- 关键交互不可操作。
- 课程无法退出或恢复。
- 有严重崩溃或数据损坏。
- 语音能力以模拟结果冒充真实结果。
- 儿童录音未经明确设计被上传或长期保留。
- 4GB 目标设备存在未处理的崩溃问题。
