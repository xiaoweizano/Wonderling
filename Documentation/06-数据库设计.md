# 06 数据库设计

## 1. 原则
SQLite 本地存储；数据库只保存课程进度和必要学习统计。课程静态内容由 JSON/资源包管理，不重复塞入学习记录表。

## 2. 建议表结构

### child_profiles
- `id` TEXT PRIMARY KEY
- `display_name` TEXT NULL（可选昵称，不要求真实姓名）
- `created_at` INTEGER
- `updated_at` INTEGER

### courses
- `course_id` TEXT PRIMARY KEY
- `schema_version` INTEGER
- `content_version` TEXT
- `title` TEXT
- `is_available` INTEGER

### lesson_progress
- `id` TEXT PRIMARY KEY
- `profile_id` TEXT
- `course_id` TEXT
- `current_step_id` TEXT
- `status` TEXT
- `stars` INTEGER
- `started_at` INTEGER
- `completed_at` INTEGER NULL
- `updated_at` INTEGER

### task_records
- `id` TEXT PRIMARY KEY
- `profile_id` TEXT
- `course_id` TEXT
- `step_id` TEXT
- `task_type` TEXT
- `attempts` INTEGER
- `is_completed` INTEGER
- `is_correct` INTEGER NULL
- `elapsed_ms` INTEGER
- `created_at` INTEGER

### vocabulary
- `profile_id` TEXT
- `word_id` TEXT
- `last_seen_at` INTEGER
- `seen_count` INTEGER
- `correct_count` INTEGER
- PRIMARY KEY (`profile_id`, `word_id`)

### learning_mastery
- `profile_id` TEXT
- `word_id` TEXT
- `mastery_level` REAL
- `last_reviewed_at` INTEGER
- PRIMARY KEY (`profile_id`, `word_id`)

### rewards
- `id` TEXT PRIMARY KEY
- `profile_id` TEXT
- `reward_type` TEXT
- `reward_id` TEXT
- `earned_at` INTEGER

### app_settings
- `key` TEXT PRIMARY KEY
- `value` TEXT
- `updated_at` INTEGER

## 3. 约束与索引
- 外键按需启用并验证。
- `lesson_progress(profile_id, course_id)` 建唯一约束或明确多次学习记录策略。
- 对 `task_records(profile_id, course_id, created_at)` 建索引。
- 时间统一使用 UTC epoch 或统一 ISO 8601，整个项目保持一致。
- 数据库升级使用有序 Migration，记录 `user_version`。

## 4. 数据访问
UI 不直接执行 SQL。使用 Repository 接口，例如：
- `IProgressRepository`
- `ITaskRecordRepository`
- `ISettingsRepository`

数据库操作应异步化或放到后台线程；返回 Unity 主线程更新 UI。

## 5. 隐私与删除
- 不要求儿童真实姓名、生日或精确位置。
- 默认不存原始录音。
- 提供清除本地学习数据的家长入口（后续家长端实现）。
- 删除档案时按规则删除关联进度和学习统计。
- 不收集与教学无关的数据。
